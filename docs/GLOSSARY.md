# Glossary

| Term | Meaning |
|------|---------|
| `.proto` | Schema file describing messages and RPC services |
| RPC | Remote procedure call — a named server method |
| Encode / decode | Convert Kotlin maps ↔ protobuf bytes |
| Transport | How bytes travel (HTTP, Connect, native gRPC) |
| Method map | Generated list of services/methods and types |
| Codec | Encode/decode helper for one message type |
| KMP | Kotlin Multiplatform — shared code for Android, iOS, JVM |
| Connect | HTTP-based RPC protocol compatible with protobuf |
| Interceptor | Middleware around a unary call (auth, logging) |
